# Tamper Hub design system

Tamper Hub is an operations dashboard for non-technical users running document-tamper model workflows. Preserve its calm, trustworthy, information-dense desktop application character.

- Use the existing system sans-serif typography, warm off-white workspace, white cards, navy text, slate secondary text, blue primary actions, green success, and red validation states.
- Preserve the persistent left navigation and two-column training workspace.
- Use medium-radius cards, thin neutral borders, subtle shadows, compact form labels, and generous but practical spacing.
- Prefer plain-language labels and short helper text. Hide advanced implementation detail by default.
- Form controls should be accessible, keyboard-friendly, and show selection counts and summaries.
- The training wizard remains four steps: Compute, Datasets, Configuration, Review.
- Dataset configuration should offer a safe recommended default and a clearly separated custom mode.
- Configuration should expose common ML platform fields in grouped controls, while retaining the selected template as the source for settings that are not exposed.
