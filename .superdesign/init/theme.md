# Theme

## Compact token summary

- Framework: React 19 + Vite, custom vanilla CSS.
- Palette: warm off-white workspace, white cards, dark navy text, muted slate text, blue primary/action, green success, red danger.
- Typography: system sans-serif stack; compact labels, strong section headings, tabular metrics.
- Shape: medium rounded cards and controls; thin neutral borders; subtle card shadows.
- Layout: persistent sidebar, responsive two-column workspace, stacked cards below tablet width.
- Forms: `.field`, `.picker`, `.compute-option`, `.wizard-panel`, `.two-columns`, `.form-actions`.
- Responsive breakpoints and all raw tokens live in `src/styles/global.css` (2,017 lines); pass relevant selector ranges rather than the entire file.
