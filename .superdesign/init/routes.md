# Routes

This React/Vite app uses state-based navigation in `src/app/App.tsx` rather than URL routing.

- `training` → `src/pages/TrainingPage.tsx` inside `src/components/layout/AppLayout.tsx`
- `datasets` → `src/pages/DatasetsPage.tsx`
- `inference` → `src/pages/InferencePage.tsx`
- `evaluation` → `src/pages/EvaluationPage.tsx`
- `comparison` → `src/pages/ComparisonPage.tsx`
- `jobs` → `src/pages/JobsPage.tsx`
- `settings` → `src/pages/SettingsPage.tsx`

Navigation metadata is defined in `src/app/navigation.ts`.
